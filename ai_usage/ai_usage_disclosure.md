# AI Usage Disclosure

## AI Tool
ChatGPT by OpenAI.

## How AI Was Used

ChatGPT assisted with understanding the problem statement, planning the project architecture, designing database tables, generating Python scripts, writing SQL queries, debugging and preparing documentation.

AI assistance was used in the following areas:

- Database schema and relational design.
- Synthetic master and transaction data generation.
- DuckDB database operations.
- Skill-gap analysis.
- Rule-based course recommendations.
- Budget reconciliation and allocation.
- Anomaly scenario generation.
- Data validation and automated testing.
- SQL seed export and restoration verification.
- README and technical documentation.

## Where AI Accelerated Development

AI accelerated code scaffolding, SQL development, debugging, implementation of business rules and preparation of documentation.

It helped identify edge cases involving foreign keys, missing skill assessments, course prerequisites, availability, capacity and budget constraints.

## Where AI Assistance Was Significant

AI assistance was substantial in generating and refining Python scripts, SQL queries and validation logic. Generated code was not assumed to be correct without execution and testing.

## Transparency

The project source code, generated datasets, validation scripts and supporting reports are included in this repository for independent review.
